# Vortex — лаунчер плейсов Roblox

**Vortex** — быстрый нативный лаунчер Roblox для Windows на **Tauri 2 + Rust**. Он объединяет каталог игр, библиотеку, точный браузер публичных и приватных серверов с реальным пингом, внутриигровой оверлей, игровые хоткеи, Discord Rich Presence и подробный учёт игрового времени.

## Установка и обновление

1. Скачайте установщик `Vortex.Launcher.Setup.1.3.0.exe` для Windows x64 со страницы [GitHub Releases](https://github.com/mozrg/Vortex/releases).
2. *(Рекомендуется)* Проверьте целостность файла по контрольной сумме `.sha256` в PowerShell:
   ```powershell
   Get-FileHash .\Vortex.Launcher.Setup.1.3.0.exe -Algorithm SHA256
   ```
3. Для запуска игр требуется установленный **Roblox Player**.

Vortex автоматически проверяет выходы новых версий на GitHub, сверяет SHA-256 перед установкой и показывает полную историю изменений по кнопке **«Посмотреть обновления»**. Ручная проверка доступна в **Настройки → Версия → Проверить обновление**.

## Возможности

### Каталог и рекомендации
- Поиск по названию, **Place ID** или прямой ссылке Roblox, переключение вида (плитки / список), фильтры по жанрам и платным играм, режим «Игра вслепую».
- Персональная подборка **«Для вас»** на основе истории и избранного с объяснением выбора и кнопками «Не интересно» / «Больше такого».

### Страница игры, реальные регионы и приватные серверы
- **Публичные серверы с реальным регионом и вашим пингом.** При подключённой `.ROBLOSECURITY` cookie Vortex определяет реальный дата-центр каждого сервера (`EU · FRA`, `EU · AMS`, `US · NYC`, `SA · GRU`, `ASIA · SIN` и т.д.) через `gamejoin.roblox.com` + GeoIP и замеряет **ваш реальный пинг** до него (TCP RTT по физическому интерфейсу + 21 ms `DataPing`), а не средний пинг игроков. Доступен фильтр таблицы по региону.
- **Приватные серверы (свои и друзей).** Отображаются первыми во вкладке **«Серверы»** (управляются галочкой «Показывать приватные серверы»):
  - прямой вход по `accessCode`, статус заполненности и деактивированных серверов, реальный регион/пинг для активных инстансов;
  - **создание приватного сервера** прямо из лаунчера с отображением цены (`Бесплатно` / стоимость в Robux) и проверкой баланса;
  - **встроенные настройки приватного сервера**: переименование, включение/выключение, копирование / перегенерация / отключение ссылки-приглашения, доступ друзьям и добавление/удаление игроков по нику.
- **Параметры запуска для каждого плейса.** Выбор стратегии при нажатии «Играть» (обычный сервер, лучший пинг, меньше игроков, предпочитаемый регион, сохранённый приватный сервер) и опция скрытия лаунчера.
- Вкладки открытых игр в верхней части окна и создание ярлыков на рабочем столе.

### Внутриигровой оверлей (HUD)
- Отображается поверх активного окна Roblox как отдельное прозрачное click-through окно Windows — **без DLL-инжектов и без чтения/записи памяти игры** (безопасно для античита Byfron / Hyperion).
- **Метрики:** реальный **FPS** (`D3DKMTQueryStatistics`), реальный **пинг**, джиттер и мини-график стабильности, реальный **регион сервера**, потребление **RAM и CPU** процесса Roblox, таймер сессии, часы, счётчик друзей онлайн, всплывающие уведомления о заходе друга на ваш сервер и авто-подсказка смены сервера при плохом пинге.
- **Настройка:** 6 позиций по углам или свободное перетаскивание в любую точку экрана, масштаб, отступы, прозрачность, **автоскрытие в полноэкранном режиме** и **профиль «Минимальный» (только FPS)** для слабых ПК.

### Игровые хоткеи и управление сессией
Отдельная вкладка **Настройки → Хоткеи** (работают глобально прямо во время игры):
- **Server Hop** — быстрая смена сервера в текущем плейсе по реальному региону, минимальному пингу или малому числу игроков, с фильтром исключения посещённых серверов за последние 30 минут.
- **Rejoin** — быстрый перезаход на тот же сервер (кнопка возврата на последний сервер также доступна на Главной странице и во вкладке «Активность» даже после выхода из игры).
- **Инвайт-ссылка** — копирование ссылки на текущий сервер по хоткею (`Alt+C` по умолчанию).
- **Выключение звука Roblox** — отключает звук только у процесса `RobloxPlayerBeta.exe` через Windows Audio Mixer (WASAPI), не затрагивая Discord, браузер и другие программы.
- **Показать / скрыть оверлей** — мгновенное переключение HUD.

### Друзья, Discord Rich Presence и баланс Robux
- **Друзья:** закрепление друзей, уведомления о запуске игр, живой лог переходов закреплённых друзей и быстрый вход на сервер друга.
- **Баланс Robux:** отображается компактным бейджем рядом с аватаркой в верхней панели (автоматически скрывается в «Режиме стрима»).
- **Discord Rich Presence:** показывает текущую игру, таймер сессии и кнопку **«Присоединиться к серверу»** (кнопка автоматически скрывается при включённом «Режиме стрима»).

### Библиотека, Быстрый запуск, Трей и Активность
- **Быстрый запуск и обмен:** сохраняйте публичные игры и приватные серверы, группируйте их в папки с drag-and-drop. Делиться можно как файлом (`.vortex-folder.json`, `.vortex-collection.json`), так и **коротким кодом** — `VORTEXQL1-...` для игры и `VORTEXFD1-...` для целой папки.
- **Окно трея:** быстрый запуск избранного и папок + компактные кнопки управления текущей сессией (Инвайт, Server Hop, Rejoin, Mute).
- **Активность:** календарь, графики, сравнение периодов, серии и достижения, цели недели, итоги года и экспорт журнала сессий в CSV.

### Безопасность и приватность
- **Локальное шифрование cookie:** `.ROBLOSECURITY` шифруется средствами Windows (**DPAPI / CryptProtectData**) и отправляется **только напрямую на официальные домены `*.roblox.com`**. Подробнее — на странице [безопасности](https://vortex.mivermiver51.workers.dev/security.html).
- **Проверка ссылок и чужих подборок:** защита от поддельных доменов (lookalike, Punycode `xn--`, кириллические гомоглифы) и автоматическая проверка реального названия и автора каждой игры перед импортом файлов-подборок и кодов папок.
- **Подтверждения и «Режим стрима»:** в **Настройки → Общие** можно включить **подтверждение на запуск** и **подтверждение на удаление**. «Режим стрима» скрывает приватные серверы, баланс Robux, ID серверов и инвайт-кнопки в Discord.

## Как считается игровое время

Пока Vortex запущен (в том числе в трее), он отслеживает процесс `RobloxPlayerBeta.exe` и события входа/выхода в локальном логе Roblox. Время засчитывается только за подтверждённые интервалы. Сессии с друзьями учитываются, когда Vortex подтверждает совпадение ID сервера.

## Хранение и перенос данных

Настройки, коллекции, быстрые запуски, игровое время и журнал можно сохранить в один JSON-файл через **Настройки → Данные → Экспортировать в файл** (при импорте показывается список изменений).

| Данные | Где хранятся |
|---|---|
| Настройки, библиотека и статистика | `localStorage` в профиле WebView2 (`%LOCALAPPDATA%\com.vortex.launcher`) |
| Журнал игровых сессий | IndexedDB в том же профиле WebView2 |
| Дисковый кэш и файлы обновлений | `%APPDATA%\vortex-roblox-launcher` (`cache`, `updates`) |
| Cookie `.ROBLOSECURITY` (если подключена) | `rbx-presence.bin` в папке данных Vortex, зашифрован через Windows DPAPI |

## Архитектура проекта

- `src/` — фронтенд на чистом HTML, CSS и модульном JavaScript (без тяжёлого бандлера):
  - `src/js/app-state.js`, `app-home.js`, `app-friends.js`, `app-settings.js`, `app-sidebar.js`, `app-runtime.js`, `app-events.js`, `src/app.js` — модульная логика приложения;
  - `src/js/game-page-servers.js`, `game-overlay-settings.js`, `security-confirm.js`, `launcher-files.js`, `play-clock.js`, `release-log.js` — серверы, оверлей, безопасность, подборки и учёт времени.
- `src-tauri/src/` — нативный бэкенд на Rust (Tauri 2):
  - `game_servers.rs` — публичные/приватные серверы, создание/настройка VIP-серверов, определение реальных IP;
  - `overlay.rs`, `overlay_fps.rs`, `overlay_ping.rs`, `overlay_audio.rs` — HUD, D3DKMT FPS, физический TCP RTT пинг, WASAPI mute;
  - `friends.rs`, `roblox.rs`, `discord.rs`, `announcements.rs`, `cookie.rs`, `runtime.rs`.
- `site/` — сайт проекта (`index.html`, `updates.html`, `security.html`).
- `tests/` — автотесты модулей фронтенда на `node:test`.

## Локальная разработка и сборка

Для сборки на Windows требуются **Rust + Cargo**, **Microsoft C++ Build Tools + Windows SDK**, **WebView2**, **Node.js** и **Tauri CLI v2** ([требования Tauri для Windows](https://v2.tauri.app/start/prerequisites/#windows)).

```powershell
# Установка Tauri CLI
cargo install tauri-cli --locked --version "^2"

# Запуск автотестов (JS + Rust)
npm test
cargo test --manifest-path src-tauri/Cargo.toml

# Проверка и запуск в режиме разработки
cargo check --manifest-path src-tauri/Cargo.toml
npm run tauri:dev

# Релизная сборка приложения и NSIS-установщика
npm run tauri:build
```

Готовый исполняемый файл появится в `src-tauri/target/release/vortex-launcher.exe`, а установщик — в `src-tauri/target/release/bundle/nsis/`.
