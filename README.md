# Vortex — Roblox Place Launcher

Настраиваемый desktop-лаунчер для поиска и запуска плейсов Roblox на Electron.

## Запуск

1. Установи Node.js 22 или новее.
2. В папке проекта выполни `npm install`.
3. Запусти приложение командой `npm start`.

## Сборка для Windows

Выполни `npm run build:win`. Команда сначала обновит фирменные SVG-ресурсы, затем соберёт установщик в `dist`:

- `Vortex Launcher Setup 0.3.0.exe` — установщик с оформлением Vortex и ярлыками в меню «Пуск» и на рабочем столе.

После установки запускай лаунчер через ярлык Vortex. Появится анимированная заставка приложения, затем откроется каталог.

После установки исходники и Node.js для запуска лаунчера не нужны.

## Возможности

- Безрамочное окно со своей перетаскиваемой панелью и кнопками сворачивания, разворачивания и закрытия; меню Electron скрыто.
- Полосы прокрутки оформлены под тему Vortex.
- Каталог Roblox Discover с разделами «В тренде», «Набирают популярность», «Сейчас играют» и другими; в каждой подборке до 100 игр с подгрузкой карточек.
- Поиск игр Roblox по названию через omni-search API и по числовому Place ID.
- Карточки с обложками, раскрываемыми описаниями, количеством игроков и оценками, если Roblox отдаёт эти данные.
- Запуск через `roblox://placeId=...`; при недоступном Roblox Player открывается веб-страница запуска.
- Главная страница, стартовая подборка, избранное и недавние игры.
- Отдельные вкладки «Отзывы» со статусом «Скоро» и «В планах».
- Настраиваемая главная страница: приветствие, игра на обложке, стиль баннера, блоки и размер подборки.
- Цветовые настройки с палитрой HSL, градиентом, направлением, собственными цветами фона и панелей темы.
- Настройки карточек, эффектов, переходов между страницами, анимации карточек, языка (русский/английский) и истории запусков.
- Кэш результатов поиска и обложек на пять минут с кнопкой очистки.
- Небольшое фирменное окно запуска. Проверка обновлений помечена как запланированная и пока не выполняется.

Поиск и загрузка обложек выполняются в Electron main process напрямую к публичным endpoint Roblox, поэтому браузерный CORS-прокси не используется. Обложки остаются удалёнными изображениями Roblox CDN; локальные настройки, избранное и история хранятся на устройстве.

## Текущее состояние

Лаунчер — локальное desktop-приложение без аккаунтов Vortex и собственного сервера. Отзывы и социальные функции пока показаны как планы. Публичные Roblox API могут менять доступность и формат данных; при отсутствии сети доступны сохранённые подборки и локальная стартовая коллекция.
