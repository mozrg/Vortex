# Vortex Place Launcher

Настраиваемый desktop-лаунчер для поиска и запуска плейсов Roblox на Electron.

## Запуск и сборка

1. Установи Node.js 22 или новее.
2. В папке проекта выполни `npm ci`.
3. Для запуска из исходников выполни `npm start`.
4. Для Windows-установщика выполни `npm run build:win`.

Готовый установщик появится в `dist/Vortex Launcher Setup 0.4.0.exe`. Сборка включает кастомное окно запуска и установщик с оформлением Vortex.

## Обновления

Установленная версия при старте проверяет GitHub Releases проекта `mozrg/Vortex`. Если опубликована более новая версия, лаунчер сам скачивает `.exe` в фоне и проверяет SHA-256. Когда загрузка завершена, в приложении появится кнопка открытия проверенного установщика. Для версии из исходников (`npm start`) автообновление отключено.

Чтобы опубликовать релиз, отправь тег, совпадающий с версией в `package.json`, например `v0.4.0`. Workflow `.github/workflows/release.yml` соберёт Windows-установщик, создаст SHA-256 файл и приложит оба файла к GitHub Release.

## Сайт загрузки

Исходники отдельного сайта лежат в папке [`site/`](site/). Сайт загружает список опубликованных версий из GitHub Releases и показывает ссылки на установщики и SHA-256. Workflow `.github/workflows/pages.yml` публикует папку `site` через GitHub Pages при изменениях в `main`.

Адрес сайта после включения GitHub Pages: <https://mozrg.github.io/Vortex/>. В настройках репозитория открой **Settings → Pages** и выбери источник **GitHub Actions**. GitHub Pages пока не включён, а в репозитории ещё нет опубликованных релизов, поэтому страница станет рабочей после включения Pages и публикации первого тега.

## Возможности лаунчера

- Безрамочное окно со своей перетаскиваемой панелью и кнопками окна; меню Electron скрыто.
- Каталог Roblox Discover с подборками игр и подгрузкой результатов.
- Поиск по названию или Place ID.
- Карточки с изображениями, короткими и раскрываемыми описаниями, статистикой игроков и оценками, если Roblox отдаёт эти данные.
- Запуск через `roblox://placeId=...`; при недоступном Roblox Player открывается веб-страница запуска.
- Главная страница, избранное, история запусков, вкладки «Отзывы» со статусом «Скоро» и «В планах».
- Кастомизация главной страницы, темы, цветов, градиента, плотности карточек и анимаций.
- Русский и английский языки.
- Локальный кэш поиска и обложек.

Поиск и загрузка обложек идут из Electron main process к публичным endpoint Roblox. Локальные настройки, избранное и история хранятся на компьютере.
