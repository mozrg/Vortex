# Vortex — лаунчер плейсов Roblox

Vortex — лаунчер Roblox для Windows. Он помогает находить игры, собирать свою библиотеку, запускать сохранённые серверы и следить за игровым временем.

![Версия 1.2.7](https://img.shields.io/badge/version-1.2.7-9b7cff) ![Windows x64](https://img.shields.io/badge/platform-Windows%20x64-0078D6)

## Установка и обновление

Скачай установщик Vortex для Windows x64. Рядом с установщиком доступна контрольная сумма SHA-256. Для запуска игр нужен Roblox Player. [Релизы на GitHub](https://github.com/mozrg/Vortex/releases) · [Сайт проекта](https://vortex.mivermiver51.workers.dev)

Vortex проверяет новые версии на GitHub. Проверку можно запустить вручную через **Настройки → Версия → Проверить обновление**. Сборку с тем же номером версии можно установить вручную поверх текущей. [Все версии](https://github.com/mozrg/Vortex/releases)

## Возможности

- **Каталог.** Поиск по названию, Place ID или ссылке Roblox, список и плитки, жанровые фильтры и «Игра вслепую». Подборка «Для вас» учитывает историю и избранное и объясняет, почему выбрана игра. Кнопки «Не интересно» и «Больше такого» уточняют следующие рекомендации.
- **Библиотека.** Избранное с коллекциями, недавние запуски, быстрый запуск и активность в одном разделе. Подборками и папками можно делиться через файлы. Для недавних игр с сохранённым ID сервера доступна попытка вернуться на тот же сервер.
- **Активность.** Календарь, графики, сравнение периодов, достижения и серии, цели недели и итоги года. Журнал сессий можно фильтровать по игре, дате и длительности и экспортировать в CSV.
- **Страница игры.** Обзор, медиа, серверы, друзья и параметры запуска. Игры можно открыть во вкладках в верхней части окна или создать ярлык на рабочем столе.
- **Друзья.** Закрепляй друзей, включай уведомления для отдельных людей и присоединяйся к ним, когда Roblox показывает доступный сервер.
- **Быстрый запуск и трей.** Сохраняй публичные игры и ссылки на приватные серверы, собирай их в папки и перетаскивай игры за обложку. Папки доступны в библиотеке и слева. Настройки видимости папок управляют тем, что попадает в окно трея.
- **Интерфейс.** Настраиваемая главная, темы, акцент, масштаб текста, анимации, командная палитра и поиск по настройкам. Подсказки включены по умолчанию. Выключатель находится в **Настройки → Интерфейс → Всплывающие подсказки**.

## Как считается игровое время

Пока Vortex запущен, в том числе в трее, он отслеживает Roblox Player и события входа и выхода в журнале клиента. Время засчитывается за подтверждённые интервалы. Сессии с друзьями учитываются, когда Vortex может подтвердить совпадение ID сервера.

При первом обновлении с версии, где использовался старый учёт времени, Vortex пересчитывает итоги по доступному журналу сессий. Если за старые игры сохранились только суммарные оценки, отображаемое время может уменьшиться или стать нулевым. Старые оценки входят в резервную копию при экспорте. При обычном обновлении поверх 1.2.4 подтверждённые часы сохраняются.

## Хранение и перенос данных

Настройки, коллекции, быстрые запуски, игровое время и журнал можно сохранить в одном JSON-файле через **Настройки → Данные → Экспортировать в файл**. При импорте Vortex показывает изменения и позволяет выбрать, какие данные принять.

| Данные | Где хранятся |
|---|---|
| Настройки, библиотека и статистика | `localStorage` в профиле WebView2 под `%LOCALAPPDATA%\com.vortex.launcher` |
| Журнал игровых сессий | IndexedDB в том же профиле WebView2 |
| Дисковый кэш и файлы обновлений | `%APPDATA%\vortex-roblox-launcher`, папки `cache` и `updates` |
| Cookie `.ROBLOSECURITY`, если подключён аккаунт | `rbx-presence.bin` в папке данных Vortex, зашифрован через Windows DPAPI |

Vortex обращается к Roblox за каталогом, обложками и статусами друзей, а к GitHub — за релизами, новостями и планами. Доступность списка друзей и статусов зависит от настроек видимости Roblox. При подключении аккаунта cookie используется для авторизованных запросов к Roblox.

## Локальная разработка

Интерфейс написан на HTML, CSS и JavaScript и находится в `src/`. Rust-команды, конфигурация Tauri 2 и упаковка установщика находятся в `src-tauri/`.

Для сборки на Windows нужны Rust с Cargo, Microsoft C++ Build Tools с Windows SDK, WebView2 и Tauri CLI. Node.js используется для вспомогательных скриптов проекта. [Требования Tauri для Windows](https://v2.tauri.app/start/prerequisites/#windows)

```powershell
cargo install tauri-cli --locked --version "^2"
cargo check --manifest-path src-tauri/Cargo.toml
cargo tauri dev
cargo tauri build --ci --bundles nsis
```

Готовый установщик появится в `src-tauri/target/release/bundle/nsis/`. Чтобы собрать только приложение для локальной проверки, выполни `cargo tauri build --ci --no-bundle` и запусти `src-tauri/target/release/vortex-launcher.exe`.
