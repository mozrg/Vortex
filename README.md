# Vortex — лаунчер плейсов Roblox

Vortex — десктопный лаунчер для Windows: поиск плейсов Roblox, избранное, учёт времени игры, статусы друзей и переход на их серверы — всё вне браузера.

## Что умеет

- **Поиск игр** — находи плейсы Roblox по названию или Place ID, просматривай каталог открытий, кэш хранится локально.
- **Твоя полка** — избранные игры, список недавних и главная страница, которую ты собираешь сам: главная игра, подборка, приветствие, раскладка.
- **Учёт времени игры** — часы на карточках: главная, избранное, недавние, каталог. Сессии записываются при запуске, с потолком 3 часа.
- **Друзья** — список друзей Roblox с аватарками и статусами. Аккаунт определяется автоматически из локального Roblox-клиента. Наведи на карточку — увидишь, во что друг играет; кнопкой play заходишь на его сервер.
- **Переход на сервер друга** — запускает `roblox://placeId=...&gameInstanceId=...`.
- **Трей** — компактное меню в стиле Steam: недавние игры с обложками, запуск в один клик, выход.
- **Настройки лаунчера** — палитры акцентов, свои цвета темы, светлая/тёмная/OLED, скругления, плотность, анимации, масштаб трея, порядок разделов перетаскиванием.
- **Перенос данных** — экспорт и импорт всех данных лаунчера одним файлом.
- **Автообновление** — проверка GitHub Releases, загрузка и установка обновлений с прогрессом.

## Где хранятся данные

Всё хранится локально на твоём компьютере. Никуда ничего не выгружается.

| Данные | Где | Что это |
|---|---|---|
| Настройки, избранное, недавние, статистика, кэши | `localStorage` (`vortex.*`) в `%APPDATA%\vortex-roblox-launcher` | интерфейс, твои списки, наигранные часы |
| Ник Roblox (опционально) | тот же `localStorage` | для публичного списка друзей |
| Cookie `.ROBLOSECURITY` (опционально) | `%APPDATA%\vortex-roblox-launcher\rbx-presence.bin` — зашифрован через DPAPI Windows | полный доступ к аккаунту; отправляется только на `presence.roblox.com` |
| Логи обновлений | `%APPDATA%\vortex-roblox-launcher\updates` | журнал установки обновлений |

Раздел друзей работает без cookie: список берётся из публичных эндпоинтов Roblox. Cookie нужен только для точных статусов — Roblox скрывает их от анонимных запросов.

Полное удаление данных — удалить папку `%APPDATA%\vortex-roblox-launcher`. Деинсталляция приложения эту папку не трогает.

## Сетевые заапросы

| Эндпоинт | Зачем |
|---|---|
| `users.roblox.com`, `friends.roblox.com`, `presence.roblox.com`, `thumbnails.roblox.com`, `games.roblox.com`, `apis.roblox.com` | поиск игр, детали, иконки, друзья, статусы |
| `api.github.com`, `github.com` | проверка обновлений и загрузка установщика |
| протокол `roblox://` | запуск игр |

Эндпоинты Roblox неофициальные и могут измениться. Телеметрии приложение не отправляет.

## Разработка

```bash
npx electron .      # запустить из исходников
```

Нужны Node.js и Windows. Сделано на Electron.
