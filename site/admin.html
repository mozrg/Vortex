Доступ

Страница открыта всем, но без токена она ничего не может: ключ есть только у вас. Токен хранится в этом браузере и отправляется только на api.github.com.

Fine-grained (рекомендую): github.com/settings/personal-access-tokens/new → Repository access: Only select repositories → mozrg/Vortex → Permissions → Contents: Read and write.

Classic: github.com/settings/tokens → Generate new token (classic) → отметьте public_repo. Этот вариант даёт доступ ко всем публичным репозиториям, поэтому fine-grained безопаснее.
