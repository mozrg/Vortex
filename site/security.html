Безопасность Vortex

Прозрачно объясняем, как лаунчер работает с cookie Roblox, куда отправляются запросы, как проверить целостность установщика по SHA-256 и почему внутриигровой оверлей безопасен для клиента.

01 · COOKIE

Что Vortex делает с .ROBLOSECURITY

Подключение cookie полностью опционально: каталог, поиск, избранное, быстрый запуск, трекинг времени и счётчик FPS работают и без авторизации.

  • Cookie хранится только локально на вашем ПК в %APPDATA%\vortex-roblox-launcher\ и шифруется средствами Windows (DPAPI / CryptProtectData), привязанными к вашей учётной записи Windows.
  • Значение cookie никогда не выводится в логи, не сохраняется в экспортируемые резервные копии и не передаётся в интерфейс без необходимости.
  • В любой момент cookie можно полностью удалить одной кнопкой в Настройки → Интеграции.
02 · СЕТЬ

Куда отправляется cookie

Vortex не имеет собственного бэкенд-сервера для аккаунтов и никогда не отправляет cookie третьим лицам. Все авторизованные запросы идут напрямую по HTTPS на официальные домены *.roblox.com:

  • users.roblox.com — имя, ID и аватар вашего аккаунта;
  • friends.roblox.com и presence.roblox.com — список друзей и статус «в игре»;
  • games.roblox.com и gamejoin.roblox.com — приватные серверы, их настройки и реальный IP дата-центра для замера вашего пинга;
  • economy.roblox.com — отображение баланса Robux рядом с аватаркой.
03 · SHA-256

Как проверить подлинность установщика

Каждый релиз на GitHub Releases публикуется вместе с файлом контрольной суммы .sha256. Перед установкой вы можете убедиться, что файл не был изменён:

Get-FileHash .\Vortex.Launcher.Setup.1.2.9.exe -Algorithm SHA256

Сравните выведенную строку с содержимым файла Vortex.Launcher.Setup.1.2.9.exe.sha256 на странице релиза. При полном совпадении файл на 100% идентичен официальной сборке. Кроме того, встроенный автообновлятор Vortex автоматически сверяет SHA-256 перед установкой каждого обновления.

04 · ОВЕРЛЕЙ

Оверлей не вмешивается в клиент Roblox

Внутриигровой HUD спроектирован так, чтобы быть полностью безопасным для клиента Roblox и античита Byfron / Hyperion:

  • Оверлей — это обычное отдельное прозрачное окно Windows поверх экрана (клики проходят сквозь него прямо в игру).
  • Лаунчер не делает DLL-инжектов, не ставит хуки на DirectX/Vulkan, не читает и не изменяет память RobloxPlayerBeta.exe и не правит файлы клиента.
  • FPS считывается через официальный системный счётчик видеодрайвера Windows (D3DKMTQueryStatistics), RAM/CPU — через стандартные Win32 API (K32GetProcessMemoryInfo, GetProcessTimes), а пинг — коротким TCP-рукопожатием до edge-узла дата-центра Roblox.
05 · ССЫЛКИ И ПОДБОРКИ

Защита от поддельных ссылок и чужих подборок

При добавлении ссылок или импорте чужих файлов-подборок (.vortex-folder.json, .vortex-collection.json, кодов VORTEXQL1- и VORTEXFD1-):

  • Vortex проверяет домен и предупреждает о подделках (подмена букв кириллицей, Punycode xn--, сторонние домены вместо настоящего roblox.com).
  • Перед добавлением подборки или запуском (если включено подтверждение запуска) показывается реальное название игры и её автор из Roblox API.
